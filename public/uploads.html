How uploads behave

  1. Choose "Fast" (8 parallel) for many small files, or "One at a time" for a slow or shared connection.
  2. A chosen or dropped folder uploads every file inside it, subfolders included, directly into the destination. Subfolder structure is not recreated.
  3. Without "Replace files with the same name", a file whose name already exists in the destination is refused, never overwritten.
  4. Transfers are not resumable: pausing, or a dropped connection, means that file restarts from the beginning.
